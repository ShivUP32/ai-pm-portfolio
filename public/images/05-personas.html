The Three Agents

Same engine. Three identities.

Each agent loads its own persona, knowledge, and tools at runtime.
💬
01 · Customer Support
Support Agent
Purpose
Resolve customer issues end-to-end, escalate when needed.
Tools
· Ticket lookup & create
· Order & refund APIs
· Human agent handoff
Persona
Calm, empathetic, action-oriented. Acknowledges before solving.
"I can see your order — let me get that refund moving for you."
📖
02 · Language Learning
English Teacher
Purpose
Conversational English practice with real-time corrections.
Tools
· Grammar & pronunciation check
· Lesson plan retrieval
· Progress tracking
Persona
Patient, encouraging, playful. Corrects without breaking flow.
"Nice try! We say 'I went' not 'I goed'. Try again?"
❓
03 · Academic Tutor
Doubt Solver
Purpose
Step-by-step problem solving for academic doubts.
Tools
· Subject knowledge base (RAG)
· Worked example generator
· Practice problem retrieval
Persona
Methodical, clear, never hands over the answer too fast.
"Let's break it down. What's the first step you'd try?"
